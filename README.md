# Ajaia Docs

A lightweight collaborative document editor built for the Ajaia AI-Native Full Stack Developer assignment.

## Features

- JWT login with seeded demo users
- Create, rename, edit, save, reopen documents
- Rich text: bold, italic, underline, headings, bullets and numbered lists
- Import `.txt` and `.md` files into editable documents
- Share documents with another seeded user
- Owned vs shared document sections
- Persistent database storage (SQLite locally; PostgreSQL when `DATABASE_URL` is provided)
- Validation, authorization and user-friendly errors
- Automated pytest coverage for sharing authorization
- Render deployment configuration

## Local setup

### Backend

```bash
cd backend
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# macOS/Linux
# source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env  # Windows
# cp .env.example .env  # macOS/Linux
python -m app.seed
uvicorn app.main:app --reload --port 8000
```

API: `https://ajaia-docs-1uen.onrender.com`  Swagger: `https://ajaia-docs-1uen.onrender.com/docs`

### Frontend

```bash
cd frontend
npm install
copy .env.example .env  # Windows
# cp .env.example .env  # macOS/Linux
npm run dev
```

Open `https://ajaia-docs-three-zeta.vercel.app`.

## Environment variables

Backend:

- `DATABASE_URL` — optional; defaults to SQLite `./ajaia_docs.db`
- `JWT_SECRET` — change for deployment
- `ACCESS_TOKEN_EXPIRE_MINUTES` — default 1440
- `CORS_ORIGINS` — comma-separated frontend origins

Frontend:

- `VITE_API_URL` — backend base URL, default `https://ajaia-docs-1uen.onrender.com/api`

## Deployment

The repository includes `render.yaml`. Set the generated frontend URL in the backend `CORS_ORIGINS` environment variable and use the PostgreSQL connection string generated by Render for `DATABASE_URL`.

## Scope decisions

The timebox favors a reliable document lifecycle, file import and sharing over real-time collaboration. Real-time conflict resolution, comments and advanced permission roles are intentionally outside the core scope.

## Supported file types

`.txt` and `.md`, maximum 2 MB. Markdown is imported as plain text for predictable behavior; users can then apply rich formatting in the editor.
